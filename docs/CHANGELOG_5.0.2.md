# Kitty Talents 5.0.2

> **Minecraft Forge 1.20.1** · Hotfix. Update the server and every client together.

## 🐛 Fixes
- **Yarn Ball** no longer clashes with vanilla White Wool (both were 4 string in a square, so one of them could not be crafted). New recipe: 4 string around any wool, in a plus, makes **2** Yarn Balls.
- **Cat Bed** no longer clashes with the vanilla bed (both were 3 wool over 3 planks). New recipe: wool, string, wool over 3 planks.
